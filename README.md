# Uni-MRL

Official code for **[Uni-MRL: Unified MultiModal Molecular Representation Learning with Large Language Models and Graph Neural Networks](https://link.springer.com/chapter/10.1007/978-981-96-8186-0_22)** (PAKDD 2025, DOI: `10.1007/978-981-96-8186-0_22`) .

## Overview

Uni-MRL is a unified multimodal molecular representation learning framework that integrates graph-based molecular representations with task-specific features generated by Large Language Models (LLMs). The framework combines these complementary representations through task-driven fusion and contrastive alignment for molecular property prediction.

> **Update:** This repository has been updated for public release with newer package dependencies. Reproduced results may differ slightly from the originally reported values, but the overall performance trends, relative rankings, and conclusions of the paper remain consistent.

## Environment

The recommended environment for Uni-MRL is:

- Python 3.9
- PyTorch 2.0.1
- CUDA 11.8
- PyTorch Geometric 2.3.1

Create a Conda environment and install the required dependencies:

```bash
conda create -n unimrl python=3.9 -y
conda activate unimrl
pip install -r requirements.txt
```
To verify the installation:

```bash
python check_setup.py --static-only
```

## Reproducing the Paper Results

Run the following commands from the repository root. The provided scripts reproduce the experiments reported in the paper using 10 random seeds for each dataset:

```bash
# ESOL, FreeSolv, and Lipophilicity (10 seeds each)
bash reproduce_physical.sh

# All 12 QM9 targets (10 seeds each)
bash reproduce_qm9.sh
```

To run a single experiment, invoke `train.py` directly. For example, the following command runs Uni-MRL on ESOL using the main configuration reported in the paper:

```bash
python train.py \
  --dataset esol \
  --llm-model galactica-6.7b \
  --knowledge-type all \
  --num-samples 30 \
  --model-type gin \
  --feature-mode unimrl \
  --drop-ratio 0.0 \
  --output-dir results/single_run \
  --runs 1
```
